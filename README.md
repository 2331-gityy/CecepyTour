## ✨ Features

- **📱 Fully Responsive Design:** Clean layout optimized across all viewports (mobile, tablet, desktop).
- **✨ Interactive Navigation:** Features a sticky header that transitions gracefully on scroll, with a custom mobile toggle navigation drawer and destination dropdown.
- **🗺️ Destination Highlights:**
  - **Bandung:** Dedicated pages detailing historic sites like Braga, complete with high-quality media galleries.
  - **Bali:** Explore gorgeous spots like Sanur Beach with custom slide layouts.
  - **Yogyakarta:** Immerse in local heritage sites like Malioboro.
- **💰 Package Pricing Cards:** Beautifully presented cards detailing pricing options (Rp 2.000.000 - Rp 5.000.000) for tourist packages.
- **📞 Direct Contacts & Location:** Social connections integrated for Instagram, WhatsApp, Gmail, and Google Maps.

---

## 🛠️ Tech Stack

- **HTML5:** Clean, semantic markup designed for accessibility and search-engine friendly structures.
- **CSS3:** Custom stylesheet system utilizing modern layouts (Flexbox, Grid), sticky nav visual transitions, and custom breakpoints.
- **JavaScript (ES6):** Dynamic window scroll listener and sidebar control scripts.
- **FontAwesome:** Scalable icons for navigation and contacts.
- **Google Fonts:** Styled with the modern "Ubuntu" font family.

## 🚀 Getting Started

Follow these instructions to set up the project locally:

### Prerequisites

All you need is a modern web browser. To avoid path routing issues when opening files directly, running a local HTTP server is recommended.

### Local Setup

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/RendyPakeY/CecepyTour.git
   ```

2. **Navigate to the Directory:**
   ```bash
   cd CecepyTour
   ```

3. **Start a Local Server:**
   *Using Python:*
   ```bash
   python -m http.server 8000
   ```
   *Using Node.js (serve packages):*
   ```bash
   npx serve .
   ```

4. **Launch the Application:**
   Open your browser and head to `http://localhost:8000` (or the port specified by your local server tool).
